# Mathematical proof-to-code map for E3

1. **Universal theorem and normalization.** The manuscript defines the tetrahedral rank-two projection and the rectangular contraction objective with the complex conjugation convention stated there.
2. **Dimension-free reduction.** The analytic argument (in the paper appendix) reduces the universal inequality to a labelled-subspace trace inequality using unitary/antiunitary SIC covariance, isometric extremizers, Pauli-Klein amplification, and tetrahedral symmetrization. These statements must be reviewed as mathematical lemmas: no code execution alone proves this interpretation.
3. **Formal moment algebra.** `E3_certificate/algebra.py` canonicalizes cyclic words, `moments.py` imposes tetrahedral symmetry, and `E3_certificate/certificate_data.json.gz` stores the explicit seven Gram blocks and reduced bases. The SOS identity involves 356 field-valued coefficient equations over Q(sqrt2,sqrt3) with 353 pivot variables and 2822 fixed free coefficients.
4. **Full independent row construction.** `ind/build_fast_exact.py` reconstructs all 356 equations by independent integer field arithmetic from the original canonical-word rules and the supplied SOS data; it writes `ind/fast_exact_rows.json.gz`. Uses no FLINT.
5. **Three dependent equations.** `ind/verify_omitted_from_exact_data.py` checks exact algebraic dependence of rows 0, 225 and 260 on the other equations, including their four field-valued right-hand-side components.
6. **353 pivot equations.** `ind/make_certified_integer_data.py` converts exact coefficient rows to rational approximants and provides certified algebraic coefficient bounds based on integer square roots. `ind/certify_inverse_rational.cpp` checks a posteriori existence, uniqueness and a rigorous pivot error enclosure using GMP rationals; floating approximate inverse is *not* accepted as proof by itself.
7. **Seven Gram matrices strictly positive.** `prior/check_rounded_grams.cpp` verifies exact rational LDL^T positivity of all seven rationalized real-embedded Hermitian Gram blocks, while the rigorous pivot bound transfers it to the algebraic blocks by perturbation. `prior/check_rounded_symmetry.py` checks the complex-Hermitian embedding shape.
8. **Sharpness.** `ind/verify_2to3_sympy_independent.py` symbolically checks the 2-to-3 symmetric-square construction. The original `E3_certificate/verify_2to3_exact.py` is an independent alternative using FLINT.
9. **Physics.** `physical_checks` exercises one 40-by-40 energy-preserving completion and finite tapered-bath examples, not all finite reservoirs. The physical lower bounds and asymptotic upper construction are analytic arguments in the manuscript, distinct from item 3–8.

## Verification boundary
The exact code certifies a finite SOS identity and positivity. It is not a Lean/Coq proof of the tracial-moment mathematical reduction; that reduction is stated in the manuscript. No tests establish absolute bibliographic priority. The input matrices are *published certificate data*, not generated experimental observations.
